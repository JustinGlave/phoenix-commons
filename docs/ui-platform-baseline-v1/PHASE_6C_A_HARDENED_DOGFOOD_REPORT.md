Specifically:
1. Run `dist\Phoenix6cASetup.exe` (the installer for the throwaway
   scaffold; nothing production-touching).
2. Walk through the installer wizard (Next → Install → Finish);
   accept defaults.
3. Verify install completes at `{localappdata}\ATS Inc\Phoenix 6C A\`.
4. Launch the installed exe. Verify the window opens; process alive
   ≥ 3 s.
5. Confirm user-data path created at `%APPDATA%\ATS Inc\Phoenix 6C A\`.
6. Uninstall via Add/Remove Programs (or `unins000.exe`); verify
   the install directory is removed.
7. Document S1 behavior during installer execution + during installed-
   exe launch (both events involve unsigned bootloader execution; S1
   may or may not trigger differently than during build).

Phase 6C-B is the highest-value next step because it validates the
runtime half of the build pipeline. Once 6C-B clears, Phase 6C-C
(updater dry-run) and Phase 6C-D (PCC v2.0.0 first official release)
follow naturally.
