STYLESHEET LOADING PATTERN
------------------------------------------------------------
Load phoenix_style.qss via _resource_path at app startup.
Always include a full embedded fallback string (_EMBEDDED_QSS)
so that auto-updates (which only replace the .exe, not _internal/)
still get correct styling. Pattern:

    qss_path = _resource_path("phoenix_style.qss")
    if os.path.exists(qss_path):
        with open(qss_path, "r") as fh:
            app.setStyleSheet(fh.read())
    else:
        app.setStyleSheet(_EMBEDDED_QSS)

_resource_path resolves to sys._MEIPASS when frozen (PyInstaller),
or the script directory in dev:

    def _resource_path(filename: str) -> str:
        if getattr(sys, "frozen", False):
            base = Path(getattr(sys, "_MEIPASS", ""))
        else:
            base = Path(__file__).parent
        return str(base / filename)

------------------------------------------------------------
COMPONENT HELPER CLASSES  (paste near top of main .py file)
------------------------------------------------------------
These must be used instead of raw QPushButton / QTableWidget.

    class PrimaryButton(QPushButton):
        """Red primary-action button."""
        def __init__(self, text: str, parent=None):
            super().__init__(text, parent)
            self.setMinimumHeight(36)
            self.setCursor(Qt.CursorShape.PointingHandCursor)

    class SecondaryButton(QPushButton):
        """Blue secondary-action button."""
        def __init__(self, text: str, parent=None):
            super().__init__(text, parent)
            self.setObjectName("secondaryButton")
            self.setMinimumHeight(36)
            self.setCursor(Qt.CursorShape.PointingHandCursor)

    class TertiaryButton(QPushButton):
        """Outline low-emphasis button."""
        def __init__(self, text: str, parent=None):
            super().__init__(text, parent)
            self.setObjectName("tertiaryButton")
            self.setMinimumHeight(36)
            self.setCursor(Qt.CursorShape.PointingHandCursor)

    class PhoenixTable(QTableWidget):
        """Read-only data table with Phoenix styling defaults."""
        def __init__(self, rows: int, cols: int, parent=None):
            super().__init__(rows, cols, parent)
            self.verticalHeader().setVisible(False)
            self.setEditTriggers(QTableWidget.EditTrigger.NoEditTriggers)
            self.setSelectionMode(QTableWidget.SelectionMode.NoSelection)
            self.setFocusPolicy(Qt.FocusPolicy.NoFocus)
            self.setAlternatingRowColors(True)

------------------------------------------------------------
BUTTON USAGE RULES
------------------------------------------------------------
PrimaryButton   — main / destructive actions (Save, Submit, New, Delete)
SecondaryButton — supporting actions (Export, Batch Add, Check All, Close)
TertiaryButton  — low-emphasis / cancel / dismiss (Cancel, What's New, ✕)

Special buttons that have their own QSS objectName (do NOT use helpers):
  - "Install & Restart"  → setObjectName("InstallBtn")
  - "Restore Job"        → setObjectName("RestoreBtn")

------------------------------------------------------------
OBJECTNAME CONVENTIONS  (QSS targets these by name)
------------------------------------------------------------
Panels / cards:       widget.setObjectName("Panel")        → dark rounded card
Stat cards:           widget.setObjectName("StatCard")     → same as Panel
Page title:           label.setObjectName("ProjectTitle")  → 14pt bold white
Page subtitle:        label.setObjectName("ProjectSubtitle") → 10pt muted
Section title:        label.setObjectName("SectionTitle")  → 12pt semibold
Pass badge:           label.setObjectName("PassBadge")     → green pill
Fail badge:           label.setObjectName("FailBadge")     → red pill
Archived badge:       label.setObjectName("ArchivedBadge") → amber pill
Step badge:           label.setObjectName("StepBadge")     → blue circle
Tag preview:          label.setObjectName("TagPreview")    → blue 10pt
Row separator:        widget.setObjectName("RowSep")       → subtle divider
Update banner:        widget.setObjectName("UpdateBanner")
Update message:       label.setObjectName("UpdateMsg")

Dynamic badge refresh pattern (for PASS/FAIL state changes):
    label.setObjectName("PassBadge")   # or "FailBadge" or ""
    label.style().unpolish(label)
    label.style().polish(label)

------------------------------------------------------------
LAYOUT RULES  (8px grid)
------------------------------------------------------------
Main window content margins:  16px all sides
Spacing between major sections: 16px
Spacing within a section:     8px
Spacing within a form row:    6-8px
Button minimum height:        36px
Input minimum height:         36px (via QSS padding)
Table row height (data rows): 42px

Always use QHBoxLayout / QVBoxLayout. Never use absolute positioning.
Use addStretch() to push content; use setSpacing() and setContentsMargins()
explicitly — never rely on Qt defaults.

------------------------------------------------------------
INLINE setStyleSheet RULES
------------------------------------------------------------
Never use setStyleSheet() on individual widgets for colors, fonts,
or borders that are already in the QSS.
The only acceptable inline styles are for dynamic per-item colors
that cannot be expressed with objectName (e.g. tree item foreground
set via QBrush, not stylesheet).
